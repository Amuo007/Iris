Iris AI

Iris looks at screenshots of the page and uses real mouse and keyboard input, like a person. It never runs scripts inside the sites you visit.

Usage

What Iris has used on your model server.

Rules

Things Iris must always or never do, one per line. For example: "Never delete emails", "Always use DuckDuckGo to search", "Ask me before submitting any form".

My info

Iris uses these to fill forms and log in for you. Secret fields are encrypted with your Mac's keychain and are never shown to the model: it types a placeholder like {{Password}} and Iris swaps in the real value as it types.

Skills

Shortcuts Iris learned about websites (a direct search URL, where a button is). It sees them the next time it visits that site, so repeat tasks get faster. Remove any that are wrong.

Accounts Iris created

Sites where Iris signed you up, with the login it used.

Schedule

Tasks that start on their own, in a new tab, while Iris is open. Use "Every" for a repeating interval or "At" for once a day.
