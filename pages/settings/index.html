Iris AI

Iris looks at screenshots of the page and uses real mouse and keyboard input, like a person. It never runs scripts inside the sites you visit.

Look-ups

Quick text look-ups outside the browser: web search results, papers with abstracts, encyclopedia summaries and public pages. Smart mode uses them to plan, and Iris can use a few during a task. They never use your tabs, cookies or logins, and never contact LinkedIn, Facebook, Instagram, X, TikTok or sites where Iris has an account for you.

Coding agents

Let a coding agent (Claude Code, OpenCode, Codex…) use Iris to look at what it is building: it gets screenshots of the current tab and can click, type and scroll there, like Iris does. Iris's own model does not run. Only programs on this Mac with the secret key can connect.

Applications

      
Every job Iris applied to, skipped, or left for you to finish.

      

    


    

      
Skills

      

        Shortcuts Iris learned about websites (a direct search URL, where a button is). It sees them
        the next time it visits that site, so repeat tasks get faster. Remove any that are wrong.
      

      

      
Your skills

      

        Teach Iris how you like a kind of task done. When a task mentions one of the words, Iris follows
        your instructions. Leave the words empty to use a skill for every task.
      

      

      

        
      

      
Plans that worked

      

        When a Smart task finishes, its plan and the sites that worked are kept. A similar task later
        starts from that plan.
      

      


    


    

      
Accounts Iris created

Schedule
